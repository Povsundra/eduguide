notes:
  - >
    The curriculum emphasizes practical software engineering rather than
    theoretical computer science, with dedicated courses in Software Analysis
    and Design, Software Engineering Fundamentals, Software Quality Assurance,
    Frontend JavaScript Development, Backend Development using Node.js and Java,
    Linux, Version Control, and a compulsory internship and Final Year Project.
  - >
    Students can further specialize through electives in Artificial
    Intelligence, Machine Learning, Cloud Computing, Data Analytics, Ethical
    Hacking, Natural Language Processing, and Cloud Solutions Architecture,
    making the program highly aligned with current software industry demands.
